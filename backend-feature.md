## Back-End Developer
Nama: Fauzi
Peran: Back-End Developer
Kelompok: Kelompok 7
Mata Kuliah: Software Development

## Deskripsi Peran
Back-End Developer bertanggung jawab atas logika aplikasi disisi server, pengelolaan data, dan penyediaan API yang dipakai oleh bagian front-end.

## Kontribusi
- Merancang dan membuat struktur database
- Membuat API (endpoint) untuk kebutuhan aplikasi
- Mengelola autentikasi dan validasi data
- Menghubungkan API dengan tampilan dari sisi front-end
