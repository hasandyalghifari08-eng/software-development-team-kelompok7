# Frontend Feature

Nama: Haris
Peran: Front-End Developer
Kelompok: 7
Mata Kuliah: Software Development 

## Deskripsi Peran
Front-End Developer bertanggung jawab atas bagian antarmuka (tampilan) aplikasi yang berinteraksi langsung dengan pengguna.

## Kontribusi
- Mendesain tampilan halaman utama
- Membuat komponen UI (navbar, form, tombol, dan kartu)
- Memastikan tampilan responsif di berbagai ukuran layar
- Menghubungkan tampilan dengan fitur dari sisi back-end
